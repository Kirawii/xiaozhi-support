# 星川 SoundAir Pro 降噪耳机

售价：699 元

## 主要参数

| 项目 | 参数 |
| --- | --- |
| 降噪 | 主动降噪，最深 45dB |
| 蓝牙 | 蓝牙 5.3，支持同时连接 2 台设备 |
| 续航 | 耳机单次 8 小时（关闭降噪）；配合充电盒共 32 小时 |
| 充电 | USB-C 接口；快充 10 分钟可听 2 小时 |
| 防水 | IPX4，可防汗水和溅水；不可游泳、淋浴时佩戴，不可浸泡 |
| 重量 | 单耳 5.2g，充电盒 46g |
| 其他 | 入耳检测、触控操作 |

## 包装清单

耳机 × 2、充电盒 × 1、USB-C 充电线 × 1、耳塞套（S/M/L）× 3 对（M 号已装在耳机上）、说明书 × 1。

## 售后与保修

1. 支持七天无理由退货：需未使用，包装、配件齐全。
2. 耳机和充电盒整机保修 1 年。
3. 耳塞套属于消耗品，不在保修范围内。
4. 单只耳机或充电盒丢失不在保修范围内，可付费补购。
