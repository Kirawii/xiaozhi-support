# 退款规则

## 一、退款去向

1. 现金支付部分原路退回至原支付渠道。
2. 星川余额支付的部分退回星川余额。
3. 积分抵扣的部分退回积分账户，退回的积分保持原有效期，已过期的积分不再退回。

## 二、到账时效

以下时效自退款审核通过后计算：

| 支付方式 | 到账时间 |
| --- | --- |
| 星川余额 | 即时到账 |
| 悦付、青禾钱包 | 1 个工作日内 |
| 储蓄卡 | 3–7 个工作日 |
| 信用卡 | 3–15 个工作日，以发卡行入账为准 |
| 信用卡分期 | 退回分期本金，已产生的分期手续费不退 |

## 三、审核时效

1. 已付款未发货的订单取消后，系统自动审核，即时退款。
2. 七天无理由退货：仓库验收通过后退款，验收与复核时效见《七天无理由退货规则》。
3. 质量问题退货：确认属于质量问题后 24 小时内退款。

## 四、先行退款

金星会员申请七天无理由退货，寄出商品并填写有效物流单号后，单笔退款金额不超过 500 元（含 500 元）的，可先行退款，无需等待仓库验收。

仓库验收不通过的，商城将从星川余额或后续退款中扣回已先行退还的款项，并暂停该会员的先行退款资格 90 天。

## 五、优惠券与积分

1. 整单全部退款，且优惠券仍在有效期内的，优惠券退回账户；已过期的优惠券不退回。
2. 部分退款的，优惠券不退回。
3. 订单获得的购物积分，退款时按退款金额比例扣回。积分余额不足扣回的，按 100 积分 = 1 元从退款中扣除。
