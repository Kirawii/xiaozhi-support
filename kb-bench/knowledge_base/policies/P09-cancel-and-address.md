# 取消订单与修改地址

## 一、取消订单

| 订单状态 | 能否取消 | 退款 |
| --- | --- | --- |
| 待付款 | 可以取消；30 分钟内未付款自动取消 | 无需退款 |
| 已付款、未发货 | 可以取消 | 全额即时退款 |
| 已发货 | 不能取消，可拒收 | 见“二、拒收” |
| 预售已付定金 | 可以取消，定金不退（因商城原因无法发货的除外） | 退还尾款（如已支付） |

## 二、拒收

1. 支持七天无理由退货的商品可以拒收。商品退回仓库验收后退款，发出运费从退款中扣除：普通商品 8 元/单，大件商品 50 元/件。
2. 不支持七天无理由退货的商品（如生鲜、定制商品），不能无理由拒收；外观破损等质量问题除外。

## 三、修改收货地址

1. 未发货的订单，可在 App 中修改收货地址一次。
2. 修改地址后运费发生变化的，多退少补。
3. 已发货的订单不能修改地址，可自行联系快递公司转寄，转寄费用由买家承担。
4. 生鲜订单不能修改到偏远地区（新疆、西藏、青海）。
