# 质量问题退换货规则

## 一、什么是质量问题

以下情况属于质量问题：

1. 商品存在功能故障，或性能不符合说明书、详情页标注的参数；
2. 错发：收到的商品款式、型号、颜色与订单不符；
3. 漏发：商品或配件缺少；
4. 运输导致商品本体破损。

人为损坏、正常磨损、使用不当造成的故障，不属于质量问题。

## 二、处理方式与时限

时限自签收的次日起计算：

| 签收后时间 | 可选处理方式 |
| --- | --- |
| 第 1–7 天 | 退货退款、换货或维修 |
| 第 8–15 天 | 换货或维修 |
| 第 16 天起 | 按《保修政策》维修 |

第 8–15 天申请换货时，如同款同规格商品无货，可改为退货退款。

## 三、错发、漏发与运输破损

1. 请在签收后 48 小时内（自签收时间起算，精确到小时）通过 App 提交照片或开箱视频。
2. 超过 48 小时提交的，按一般质量问题处理，需经检测确认。
3. 漏发的商品优先补发。

## 四、凭证与检测

1. 申请时需提供故障照片或视频，必要时商城安排检测。
2. 单价超过 3000 元（不含）的数码电子产品，以及所有大家电（冰箱、洗衣机、空调、电视），需由星川授权服务网点出具检测报告后处理。
3. 检测确认不属于质量问题的，商品寄回买家，往返运费由买家承担。

## 五、运费

质量问题退换货的运费由商城承担。推荐使用免费上门取件；自行寄回的，凭快递单据申请运费补偿，补偿上限 30 元。
