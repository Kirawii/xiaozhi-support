# 特殊商品售后规则

## 一、不支持七天无理由退货的商品

| 品类 | 说明 |
| --- | --- |
| 生鲜及易腐食品 | 水果、蔬菜、肉禽蛋、鲜奶等 |
| 定制商品 | 刻字、印照片、按尺寸定制等 |
| 贴身衣物 | 内衣、内裤、袜子、泳衣，拆封后不支持；未拆封的可以七天无理由退货 |
| 已激活的电子产品 | 手机、平板、电脑、智能手表，激活后不支持 |
| 数字商品 | 充值卡、游戏点卡、电子书、软件激活码 |
| 床垫 | 拆除塑封后不支持 |

以上商品出现质量问题的，仍按《质量问题退换货规则》处理。

## 二、生鲜商品售后

1. 签收后 24 小时内发现坏果、变质、破损的，可通过 App 提交照片申请售后；超过 24 小时不予受理。
2. 坏果率 = 坏果重量 ÷ 商品净重。
3. 坏果率不超过 30%（含 30%）的，按坏果率比例退款，退款金额 = 实付金额 × 坏果率；坏果率超过 30% 的，可全额退款。
4. 冷链费不予退还，全额退款的情况除外。

## 三、定制商品

1. 下单后 2 小时内，且尚未进入制作的，可以取消订单。
2. 进入制作后不能取消。

## 四、详情页优先

商品详情页对售后有特殊说明的，以详情页说明为准。
